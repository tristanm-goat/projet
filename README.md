# projet
Utilisation du projet :

mchre091.duckdns.org (Database)

Pour utiliser les databases:
- Modifier le liens dans les documents respectifs si-dessous
  - connection_contact (pour capter les requêtes de la page 'contact')
  - connection_retirement (pour connecter aux databases statiques des données des maisons de retraites)
  - connection.php (pour la connection des comptes des utilisateurs)
 
Pour l'utilisation localhost, simplement modifier 'mchre091.duckdns.org' à 'localhost' et les valeurs username et password

Pour faire fonctionner les databases, il faut mettre les databases folder (.ibd) dans le folder 'mysql/data'
